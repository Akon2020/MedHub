# Glossaire

| Terme | Définition |
| --- | --- |
| ADT | Admission, transfert, sortie : mouvements des patients hospitalisés. |
| Append-only (ajout seul) | Table où l'on ajoute des lignes sans jamais modifier ni supprimer les existantes. |
| ATC | Classification anatomique, thérapeutique et chimique des médicaments. |
| Avoir | Écriture inverse qui annule tout ou partie d'une facture. |
| Ayant droit | Membre de la famille d'un bénéficiaire couvert par une convention. |
| Bon d'envoi | Document signé par l'employeur autorisant la prise en charge d'un agent. |
| Bootstrap | Premier chargement complet des données d'un appareil. |
| Bris de glace | Accès exceptionnel à un dossier hors des droits habituels, avec motif et traçabilité. |
| CIM-10 | Classification internationale des maladies, dixième révision. |
| Code de structure | Identifiant court et non secret d'une structure, saisi à la connexion (ex. HOP-KIN-0042). |
| Convention | Contrat entre une structure et un tiers payant. |
| CPN | Consultation prénatale. |
| DCI | Dénomination commune internationale d'un médicament. |
| DEK | Clé de chiffrement des données (Data Encryption Key). |
| DHIS-2 | Plateforme de rapportage de santé publique utilisée par de nombreux ministères. |
| DICOM | Standard d'échange d'images médicales. |
| DPI | Dossier patient informatisé. |
| FHIR | Standard d'échange de données de santé par API (HL7). |
| Garantie ou caution | Somme versée par travailleur par l'entreprise, remboursable à la résiliation. |
| HIMS | Système de gestion de l'information hospitalière. |
| HLC | Horloge logique hybride : horloge physique + compteur pour ordonner les événements. |
| Idempotence | Une opération rejouée produit le même effet qu'une seule exécution. |
| Journalier | Travailleur temporaire d'un sous-traitant, pris en charge hors forfait. |
| Local-first | L'application fonctionne d'abord sur les données locales et se synchronise ensuite. |
| LOINC | Nomenclature internationale des examens de laboratoire. |
| MRN | Numéro de dossier patient lisible. |
| Outbox | File locale des opérations en attente d'envoi au serveur. |
| Périmètre de synchronisation | Sous-ensemble des données copié sur un appareil. |
| Postnom | Second nom usuel en RDC, distinct du prénom. |
| PWA | Application web installable fonctionnant hors connexion. |
| Quatre yeux | Validation d'une action par une seconde personne. |
| RLS | Row Level Security : restriction d'accès aux lignes d'une table dans PostgreSQL. |
| SNIS | Système national d'information sanitaire. |
| Structure (tenant) | Établissement client de la plateforme. |
| Ticket modérateur | Part restant à la charge du patient après couverture. |
| Tiers payant | Entité qui paie tout ou partie des soins à la place du patient. |
| UUID v7 | Identifiant unique ordonné dans le temps, générable sans serveur. |
